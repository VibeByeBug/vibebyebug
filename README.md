## Frontend

React (Vite + TypeScript) + Tailwind CSS. See `src/` for the app source.

### Setup

```bash
npm install
npm run dev
```

Set `VITE_WS_URL` in a `.env` file to point at the backend WebSocket (defaults to `ws://localhost:8000/ws`).
